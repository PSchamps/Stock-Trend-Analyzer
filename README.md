Stock Price Trend Analyzer

A simple Java-based console application that reads stock price data from a CSV file and analyzes the overall price trend (upward, downward, or stable). Great for practicing file handling, data analysis logic, and clean code structuring in Java.

-----------------------------------------------------------------

Features

- Reads stock prices from a `.csv` file
- Detects basic stock trends (Upward / Downward / Stable)
- Simple console output
- Error handling for missing files and bad data

-----------------------------------------------------------------

Technologies Used

- Java (JDK 17+)
- IntelliJ IDEA (recommended)
- File I/O
- CSV parsing

-----------------------------------------------------------------

How to Run

1. Clone the repository
```bash
git clone https://github.com/yourusername/StockTrendAnalyzer.git
cd StockTrendAnalyzer/src

javac StockTrendAnalyzer.java

java StockTrendAnalyzer
